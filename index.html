Control de Temperatura en Reactor

Determinar la temperatura de equilibrio \(T\) (°C) para la cual se satisface el balance térmico del reactor químico.

\[ T = g(T) = 18 + 8e^{-0.15T} \qquad \Longleftrightarrow \qquad f(T) = T - 18 - 8e^{-0.15T} = 0 \]

Condición de convergencia: \(g'(T) = -1.2e^{-0.15T} \quad\rightarrow\quad |g'(20)| = \mathbf{0.059738} < 1 \quad (\text{✓ Convergencia garantizada})\)

Tiempo de Respuesta en Almacenamiento SSD

Determinar el tiempo crítico de respuesta \(t\) (ms) en el cual se estabiliza la tasa de transferencia.

\[ f(t) = t^3 - 7t - 5 = 0 \qquad \text{con} \qquad f'(t) = 3t^2 - 7 \]

Verificación de signos: \(f(2) = \mathbf{-11} < 0\), \(f(3) = \mathbf{1} > 0 \quad\rightarrow\quad \text{✓ Raíz en } [2, 3] \text{ detectada} \quad\cdot\quad f'(3) = \mathbf{20} \neq 0\)

Rendimiento de Servidor de Cómputo

Determinar la fracción normalizada de carga \(x\) en el clúster donde se equilibran la llegada de peticiones y la latencia.

\[ f(x) = e^{-x} - x^2 + 0.2 = 0 \]

Verificación de signos: \(f(0) = \mathbf{1.200000} > 0\), \(f(1) = \mathbf{-0.432121} < 0 \quad\rightarrow\quad \text{✓ Raíz en } [0, 1] \text{ detectada}\)
